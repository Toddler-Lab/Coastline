# Media credits

All photos and videos in `apps/web/public/media/` come from **Wikimedia Commons** under Creative Commons
licences. They were collected on 2026-11-18 for the drone-landing design (originally prototyped on
branch `design/drone-landing`, now implemented in `apps/web`).
`credits.json` is the machine-readable copy of this table; the UI renders credits from it.

## Licence obligations (read before reusing)

- **CC BY 3.0 / 4.0:** credit the author, link the licence, say the file was changed.
- **CC BY-SA 4.0:** the same, and an adapted image (crop, colour grade, overlay baked into the file)
  must be shared under CC BY-SA too. Overlays drawn by CSS on top of the image are not adaptations.
- Credits must stay visible somewhere a visitor can reach: the site footer lists them, and
  `docs/design.md` 3.5 already requires a credit line where a licence needs one.
- These are **placeholder-quality real photos** for design and demo. Before a public launch, replace
  or confirm each one; operator-uploaded destination photos (data model `hero photo`) take over.

## Changes made

Photos: resized to max 2200 px and re-encoded as WebP (quality 80). Videos: an 18-second segment
cut from the 1080p transcode, letterbox cropped where present, scaled to 1600 px wide, H.264 MP4,
audio removed, 0.6 s fade in/out for looping. Posters are single frames of those videos.
